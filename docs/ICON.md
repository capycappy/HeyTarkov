# アイコン

アプリのアイコンは**コードで生成**している。手描きの原画はなく、
`tools/IconMaker/Program.cs` が唯一の原本。

```
dotnet run --project tools\IconMaker
```

これで以下が出力される。

| 出力先 | 中身 |
|---|---|
| `src/HeyTarkov/app.ico` | 全9サイズ（16/20/24/32/40/48/64/128/256）を1ファイルに格納 |
| `docs/icon/icon-*.png` | 16/24/32/48/256 の PNG |
| `docs/icon/palettes.png` | 全配色 × 全サイズを、明背景と暗背景で並べた確認用シート |

`src/HeyTarkov/HeyTarkov.csproj` の `<ApplicationIcon>app.ico</ApplicationIcon>` により、
EXE のアイコンとウィンドウのアイコンの両方に反映される。

## デザインの意図

**「多数のタスクから、音声で1つを見つける」**が伝わることを条件にした。
マイクだけでは「録音アプリ」に見え、四角の重なりだけでは「ウィンドウが並んでいる」
にしか見えなかったため、次の構成に落ち着いている。

- **一覧パネル**（3行のうち1行がアクセント色）… 候補が複数あり、その1つが選ばれている状態
- **マイクのバッジ**（右下に重なる円）… 選ぶ手段が音声であること

実際のアプリ画面（候補リストから1件が選択されている状態）と対応している。

## サイズごとの描き分け

**40px 未満は別の絵を描いている。** 一覧の行は 32px あたりで潰れて意味をなさなくなるため、
小サイズでは**バッジ（円＋マイク）だけ**を表示する。

大サイズでも同じバッジが右下にあるので、サイズが変わっても同じマークとして認識できる。
タスクバーで実際に見えるのはこのバッジなので、ここは形を単純に保っている。

## 配色

`Palettes` 配列に3案あり、`P = Palettes[0]` で選んでいる。採用は **A-Gunmetal**。

| | パネル | 行 | アクセント | 輪郭 | 性格 |
|---|---|---|---|---|---|
| **A-Gunmetal**（採用） | `#35312A` | `#8A816E` | `#D2A351` | `#6E6453` | ゲームUIのタン／くすんだ金に最も近い |
| B-Olive | `#454B37` | `#98997E` | `#D97B2E` | `#7A7F5E` | ミリタリー寄り。タスクバーで最も目立つ |
| C-Steel | `#333A3E` | `#808890` | `#DCD3BC` | `#6E777D` | 無彩色。コントラストは最も高い |

### 輪郭色はインクと分ける

**輪郭をパネルより暗い色にしてはいけない。** 明背景でしか機能しない。

初版はこれをやってしまい、パネル `#24221E` と Windows のダークタスクバー `#202020` の
輝度差が2〜3しかない状態で出荷した。純黒の背景（Webページなど）では**パネルが完全に消え、
バーとバッジだけが宙に浮く**。

対策として `Rim` を `Ink`（マイクの描画色）から分離し、**明暗どちらからも離れた中間トーン**を
充てている。パネル自体の明度も `#202020` から十分離した。

色を変えるなら `Palettes` の値を書き換えて再生成する。
`palettes.png` で**明暗どちらの背景でも輪郭が保たれているか**を必ず確認すること
（暗い色だけで組むと、ダークテーマのタスクバーで消える）。

## 制約

- **文字は入れない。** 2文字でも 16px では読めない。
- **Escape from Tarkov / Battlestate Games の商標・公式アセットは使わない。** 公開物のため。
- 要素は2つまで。3つ目を足すと 48px で破綻する。
