# アイコン制作指示書 — Hey Tarkov

公開用のアプリアイコンを作るための仕様書。デザイナーに渡すか、自分で作るときの
チェックリストとして使う。

## 1. このアプリが何か（デザインの前提）

マイクボタンを押しながら Escape from Tarkov のタスク名を言うと、Wiki の該当ページが
ブラウザで開く。**ゲームに寄り添う実用ツール**であって、ゲーム本体でもチート系ツールでもない。

- ゲームプレイ中に Alt+Tab で切り替えて使う → **タスクバーで一瞬で見分けられること**が最優先
- Tarkov のロゴ・公式アセット・BSG の商標は**使わない**（公開するので権利上のリスクを避ける）
- 「音声」と「調べる」が伝わればよい

## 2. 必須の仕様

| 項目 | 値 |
|---|---|
| 最終形式 | `.ico`（マルチ解像度を1ファイルに格納） |
| 内包サイズ | **16, 20, 24, 32, 40, 48, 64, 128, 256 px** |
| 色深度 | 32bit RGBA（アルファ付き PNG 圧縮） |
| 形状 | 正方形。角丸や余白は Windows 側では付かないので、必要ならデザインに含める |
| 余白 | 256px 版で外周に 8〜16px 程度の余白を確保（タスクバーで詰まって見えないため） |

**16px と 24px は必ず個別に確認すること。** 256px の絵を縮小しただけだと潰れる。
小サイズ用に線を太くした簡略版を別途描いて、それを16/20/24pxのレイヤーに入れるのが望ましい。

## 3. デザインの方向性

**推奨: マイク + 検索/ページの組み合わせ、1モチーフに絞る**

小さいサイズで成立させるため、要素は**2つまで**。案:

| 案 | 内容 | 16pxでの見え方 |
|---|---|---|
| A（推奨） | マイクのシルエット単体、色で個性を出す | 最も強い。輪郭だけで判別可能 |
| B | マイク + 虫めがね | 要素2つ。虫めがねは小さくなると潰れやすい |
| C | 吹き出しの中にマイク | 輪郭が丸くなり他アプリと差別化しにくい |

**色**: Tarkov の画面は暗く濁った色調なので、タスクバーで埋もれないよう
**彩度の高い差し色を1色**入れる。背景は単色または2色の緩いグラデーションまで。

- ライトテーマ・ダークテーマ**両方のタスクバーで確認する**こと
- 単色の黒や濃紺だけで作ると、ダークテーマのタスクバーで消える
- 白フチ or 明るい背景面を持たせると、どちらのテーマでも輪郭が立つ

**避けること**:
- 細い線（1px の線は 16px で消える）
- 文字（"HT" などの2文字でも16pxではほぼ読めない。入れるなら128px以上でだけ見える装飾として）
- 写真・複雑なグラデーション・ドロップシャドウ多用

## 4. 納品物

```
docs/icon/
  icon-256.png     … マスター（256x256, RGBA, 余白込み）
  icon-48.png      … 中サイズ用に線を調整したもの
  icon-24.png      … 小サイズ用の簡略版
  icon-16.png      … 最小サイズ用の簡略版
  app.ico          … 上記を全部束ねたマルチ解像度 ICO
```

マスターがベクター（SVG / AI）ならそれも一緒に置く。後で作り直しやすい。

## 5. ICO への変換

PNG が揃っていれば ImageMagick で束ねられる:

```bash
magick icon-16.png icon-24.png icon-48.png icon-256.png app.ico
```

ImageMagick を使わない場合は [RealWorld Icon Editor] や [icoconvert.com] などでも可。
**変換後に必ず 16px 表示を目視確認すること**（自動縮小に任せると潰れる）。

## 6. アプリへの組み込み

`app.ico` を `src/HeyTarkov/app.ico` に置き、`HeyTarkov.csproj` に1行足すだけ:

```xml
<PropertyGroup>
  <ApplicationIcon>app.ico</ApplicationIcon>
</PropertyGroup>
```

これで EXE のアイコンとウィンドウのアイコンの両方に反映される。
（ウィンドウ側だけ別にしたい場合は `MainForm` で `Icon` を設定する）

組み込んだら:

```bash
dotnet publish src\HeyTarkov -c Release -o dist
```

`dist\HeyTarkov.exe` をエクスプローラーで見て、**一覧表示（小）** と
**タスクバー** の両方で確認する。

## 7. 確認チェックリスト

- [ ] 16px でモチーフが判別できる
- [ ] ライトテーマのタスクバーで輪郭が見える
- [ ] ダークテーマのタスクバーで輪郭が見える
- [ ] 他のアプリのアイコンと並べて、色で見分けられる
- [ ] Tarkov / BSG の商標・公式アセットを使っていない
- [ ] `app.ico` に 16〜256px が全部入っている
